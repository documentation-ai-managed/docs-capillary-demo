## Quick Start

Get up and running with Capillary Demo in minutes. Follow these steps to set up your first loyalty program.

<Steps>
  <Step title="Create Account" icon="user-plus">
    Sign up at `https://dashboard.example.com` and verify your email.
  </Step>
  <Step title="Generate API Key" icon="key">
    Navigate to the API section and create a new key for your integration.
  </Step>
  <Step title="Enroll Your First Customer">
    Use the API to add a customer to your loyalty program.

    <CodeGroup tabs="JavaScript,cURL">
      ```javascript
      const response = await fetch('https://api.example.com/v1/customers', {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${YOUR_API_KEY}`,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          email: 'customer@example.com',
          points: 100
        })
      });
      ```
      ```bash
      curl -X POST https://api.example.com/v1/customers \
        -H "Authorization: Bearer YOUR_API_KEY" \
        -H "Content-Type: application/json" \
        -d '{"email": "customer@example.com", "points": 100}'
      ```
    </CodeGroup>
  </Step>
  <Step title="Launch Campaign" icon="rocket">
    Create a personalized rewards campaign from the dashboard.
  </Step>
</Steps>
