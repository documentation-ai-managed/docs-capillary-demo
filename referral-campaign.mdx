<Callout kind="alert">
Referral Campaign can be created from the old UI only.
</Callout>

Referral campaigns help you acquire new customers by using your existing customers' networks. Existing customers can refer their friends and contacts to visit your store. You can configure your referral campaigns to reward both the referrer (the existing customers who provide their friends' email addresses or phone numbers) and the referee (the friends of existing customers who receive the invitation) when the referee enrolls in your loyalty program or makes transactions.

<Image src="https://files.readme.io/60b4a3de118488ccf31fc8f81dd0d691b934e829929b835a784ac5a5c8c97a5c-FLOWCHART_7.png" width="800" height="400" alt="Referral campaign workflow flowchart showing the process from referrer sharing code to referee registration and rewards distribution" />

## Configure a referral campaign

Follow these steps to set up a complete referral campaign from start to finish.

<Steps>
<Step title="Configure a referral code" icon="qr-code" title-type="h3">
Generate unique codes to track referrals effectively.

Referral codes are unique identifiers shared by existing customers (referrers) with their friends and contacts (referees) to promote your brand.

### Set up referral code configuration

1. Navigate to **Engage+** > **Campaigns** > **Settings**
2. On the settings page, select **Referral configuration**

<Image src="https://files.readme.io/262457b-Screenshot_2024-06-18_113333.png" width="800" height="500" alt="Referral configuration settings page showing the referral code setup options" />

3. On **Define referral code**, choose one of the following options:

<Tabs>
<Tab title="Random Code" icon="shuffle">
The system will generate random referral codes automatically.

1. In the **Minimum code length** field, enter the minimum number of characters for your referral code
2. Select **Save**
</Tab>

<Tab title="Custom Code" icon="settings">
Customize your referral codes with prefixes, suffixes, and character sets.

1. On the **Define character set** section, select your preferences:
   - **Uppercase**: Make characters uppercase
   - **Lowercase**: Make characters lowercase  
   - **Numbers**: Add numbers to your referral code

<Image src="https://files.readme.io/7f41069-Screenshot_2024-06-18_122013.png" width="700" height="400" alt="Define character set options for custom referral codes including uppercase, lowercase, and numbers" />

2. In the **Minimum code length** field, enter the minimum number of characters

3. Configure prefix (optional):
   - Enable **Add prefix** button
   - Choose **Custom string** to enter desired characters, or
   - Choose **Profile attribute** to use **First Name** or **Last Name**

<Image src="https://files.readme.io/1528ff8-custom_string.png" width="650" height="350" alt="Add prefix options showing custom string and profile attribute selections" />

   - Check **Maximum prefix length** box to set length limit

<Image src="https://files.readme.io/013adf2-Screenshot_2024-06-18_124332.png" width="650" height="350" alt="Profile attribute selection for prefix showing First Name and Last Name options" />

4. Configure suffix (optional):
   - Enable **Add suffix** button
   - Choose **Custom string** to enter desired characters, or
   - Choose **Profile attribute** to use **First Name** or **Last Name**

<Image src="https://files.readme.io/ed6b994-Screenshot_2024-06-18_135318.png" width="650" height="350" alt="Add suffix options with custom string and profile attribute configurations" />

   - Check **Maximum suffix length** box to set length limit

5. Select **Save**

<Image src="https://files.readme.io/31fb8c8-Screenshot_2024-06-24_130325.png" width="800" height="500" alt="Completed referral code configuration showing all settings saved" />
</Tab>
</Tabs>

<Callout kind="tip">
You can validate your referral code using the Validate Referral Code API if needed.
</Callout>
</Step>

<Step title="Configure referral campaign details" icon="file-text" title-type="h3">
Define the campaign's name, validity, and objective.

1. On the InTouch portal, select **Home** from the left-hand corner
2. Select **Engage+** from the sidebar menu
3. Select **Open old campaign manager**
4. Select **+New Campaign** from the **Campaigns Home** page
5. Choose **Referral** as the campaign type from the dropdown menu
6. Enter the required details for the referral campaign

### Campaign configuration fields

| Field | Description |
|-------|-------------|
| Campaign Name | Name of the campaign |
| Description | Brief description of the campaign |
| Valid between | The date range for which the campaign is valid |
| Campaign Objective | The primary objective of the campaign |
| Incentivize Referrer | When to incentivize the referrer: Dynamically as criteria is met or at the end of the campaign |
| Disable Test-Control | Enable or disable test control groups |
| Make Default for POS | Enable or disable campaign activation on POS |
| Invite Registered Customers | Enable or disable inviting previously registered customers |
| Register Customer Online | Enable or disable registering a customer online using a social app |

### Campaign objectives

<Columns cols="2">
<Card title="Acquisition" icon="users" horizontal={false}>
**General**: Acquire new transacting customers from a given acquisition channel

**Referral**: Acquire new transacting customers through referrals by an existing customer
</Card>

<Card title="Delight" icon="gift" horizontal={false}>
**Birthday/Anniversary**: Delight customers with incentives around life events

**Feedback/Survey**: Encourage customers to take surveys or provide feedback
</Card>

<Card title="Promotional" icon="percent" horizontal={false}>
**Up sell**: Encourage people to buy higher volumes of the same SKUs

**Cross-Sell**: Encourage people to buy different SKUs

**Sales Booster**: Encourage people to buy more with higher ABS and ABV
</Card>

<Card title="Miscellaneous" icon="sparkles" horizontal={false}>
**Heavy Discount Sale**: Boost sales during heavy discount periods including festivals and EOSS

**Frequency Enhancer**: Encourage lower frequency visitors to transact more frequently

**Lapsation**: Reactivate lapsed customers
</Card>
</Columns>

7. Select **Create** to create the referral campaign
</Step>

<Step title="Configure message (post referral)" icon="mail" title-type="h3">
Define communication templates for messages to be sent after the referral is completed.

You can choose from two types of messages: Email and SMS.

<Tabs>
<Tab title="Email Template" icon="mail">
### Create an email template

1. Select **Email** from the tab menu
2. Select **+Template** to open the template creator
3. Create a new email template using HTML, or import an HTML file from your system
4. Use available referral tags to build the template:

| Referral Tag | Description |
|--------------|-------------|
| Referrer Code | A unique code assigned to a referrer |
| Invitee Name | The name of the person being invited |
| Invitee Identifier | A unique identifier for the invitee |
| Referrer Full Name | The complete name of the person making the referral |
| Referrer First Name | The first name of the person making the referral |
| Unsubscribe* | Enable opt-out option (Compulsory tag) |

5. Provide a name for the template, and select **Save**
6. Select **Refresh List** to refresh the template list
7. Select the created template to preview it
8. Select **Edit Message** to begin editing the subject and text message
9. Select **Review** to finalize the changes
10. Preview the message, and select **Save**
</Tab>

<Tab title="SMS Template" icon="message-square">
### Create an SMS template

1. Select **SMS** from the tab menu
2. Enter the template message in the message section
3. Use the available preset tags to help you draft the message
4. Select **Review & Save** to save the template
5. View the message preview, and select **Save** to confirm

<Image src="https://files.readme.io/de449552b062416c3605598ccd8d18b58710a2950851b7dcf8322dec1736ccb1-image.png" width="800" height="500" alt="SMS template creation interface with message field and preset tags" />

<Callout kind="tip">
Use the available preset tags to help you draft the message.
</Callout>
</Tab>
</Tabs>

### Configure and send the message

1. Select **Incentives to Referrer** or **Incentives to Referee**
2. Select **+** beside **On Referee Registration** or **On Referee Transaction**

| Term | Definition |
|------|------------|
| Referee Registration | The action when a new customer signs up using the referral link or code |
| Referee Transaction | The qualifying purchase made by the referee after successful registration |

<Image src="https://files.readme.io/b696f36cf109540a18bc3c92b1e0c371c8a631147143e125867e2248d5a4fbc6-image8.png" width="800" height="500" alt="Incentives configuration showing On Referee Registration and On Referee Transaction options" />

3. Enter the number of registrations or transactions required to fulfill the criteria

<Image src="https://files.readme.io/27184847df6b941f1d709a4073dfeb969eb8d1cd8f1ee4b29b614843132f9b71-Screenshot_2025-10-07_at_6.22.26_PM.png" width="800" height="450" alt="Configuration interface showing number of registrations or transactions input field" />
4. Select the **Edit** icon to configure the coupon
5. Select **Create Coupon Series** to create a new coupon, or **Claim Coupon Series** to add an existing coupon
6. Enable **Notify by SMS** or **Notify by Email** under **Notification Settings**

<Image src="https://files.readme.io/e8fc2ea431dd7930af073e58c03b189f11e44d0b9499b825fc883f19b241e181-Screenshot_102.png" width="800" height="500" alt="Notification settings showing SMS and Email configuration options" />

7. Select **Configure SMS** or **Configure Email** to draft message

<Image src="https://files.readme.io/788d9ff279563dd4fcf6d521e77068d04ee0f2e3ae34e5ec53789b13e6f5d283-Screenshot_102.png" width="800" height="500" alt="Configure SMS and Email options for post-referral notifications" />

8. Select **Review and Save** to save the changes

<Image src="https://files.readme.io/9f1c2ce7e4db347b146a6757f2c5b068a228402789b485678aa2230f3a55f2b5-Screenshot_103.png" width="800" height="450" alt="Review and Save interface showing configured incentive settings" />

<Callout kind="info">
For **Incentives to Referrer**, you can add multiple registration and transaction criteria. However, for **Incentives to Referee**, multiple criteria cannot be configured.
</Callout>
</Step>

<Step title="Configure the incentives" icon="gift" title-type="h3">
Set up the rewards for the referral campaign.

Incentives are rewards designed to motivate and encourage customers. There are two types supported:

<Columns cols="2">
<div>
### Issuing Coupons

1. Select **Rewards** to configure the rewards
2. Select **Incentives to Referrer** or **Incentives to Referee**
3. Select **+** beside **On Referee Registration** or **On Referee Transaction**
4. Enter the number of registrations or transactions required
5. Select the **Edit** icon to configure the coupon

<Image src="https://files.readme.io/ba78ed42e4c216e4afcedb86e587bc20e4ab3480ca12b2490494e0b06212003e-image9.png" width="800" height="450" alt="Edit icon highlighted to configure coupon for incentives" />

6. Select **Create Coupon Series** or **Claim Coupon Series**
7. Enable **Notification Settings** for SMS or email if needed
8. Select **Save** to save the changes
</div>

<div>
### Issuing Points

1. Navigate to the edit page of the default loyalty program
2. Under **Workflows**, create a new rule to configure issuing points
3. Use these rules to issue points:
   - `referrerCode.refereeRegCount`: Track the number of referrals
   - `referrerCode.refereeTxnCount`: Track the number of transactions
4. Select **Add action** to award points
5. Choose points earn conditions and expiry conditions
6. Select communication channels
7. Select **Save and Continue** to apply the changes

<Callout kind="info">
The Award Points to Referee action is available only for workflows within the default loyalty program.
</Callout>
</div>
</Columns>
</Step>

## FAQs

<ExpandableGroup>
<Expandable title="Can we limit the number of referrals a user can make in a referral campaign?" default-open="false">
Yes, you can set limits on the incentives a user receives for referrals. For example, if you set a limit of 5, the referrer will only receive incentives for the first 5 successful referrals. Beyond that, no incentives will be given.
</Expandable>

<Expandable title="Can a customer generate a different referral code for each referral?" default-open="false">
No, each customer is issued a single unique referral code.
</Expandable>

<Expandable title="Is there an API to fetch the referral code that customers use to register themselves?" default-open="false">
Yes, there is an API to fetch the referral code customers use to register. This will retrieve the referral details, including the unique referral code. For more information, refer to the API documentation.
</Expandable>

<Expandable title="Does the referral API restrict sending multiple referral SMS to the same mobile number?" default-open="false">
Yes, the referral API restricts sending multiple referral SMS to the same mobile number. You cannot send multiple referral messages to the same recipient using the API.
</Expandable>
</ExpandableGroup>
