## Recent Updates

<Update label="2024-10-15" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- **Advanced Scenario Modeling**: Create and simulate multiple cash flow scenarios with what-if analysis directly in the dashboard. Model variables like revenue fluctuations, expense changes, and market conditions.
- **AI-Powered Forecasting**: Integrate machine learning predictions for more accurate treasury projections based on historical data.

## Breaking Changes

- Updated API endpoints for scenario data. Migrate from `/v1/scenarios` to `/v2/scenarios`.
- Removed deprecated `legacyForecast` parameter from forecast requests.

## Improvements

- Enhanced dashboard performance with 40% faster load times for large datasets.
- Improved mobile responsiveness for on-the-go treasury monitoring.

## Bug Fixes

- Fixed reconciliation errors when importing bank statements with multi-currency transactions.
- Resolved export issues for CSV reports exceeding 10,000 rows.

</Update>

<Update label="2024-09-20" description="v1.5.0" tags={["feature", "improvement", "bugfix"]}>

## New Features

- **Bank Account Reconciliation**: Automate matching of bank transactions with your accounting records.
- **Custom Alerts**: Set up notifications for low cash balances, overdue payments, or forecast deviations.

## Improvements

- Streamlined onboarding with guided setup wizards for new users.
- Added bulk import support for transaction data from Excel and CSV files.

## Bug Fixes

- Corrected calculation errors in multi-currency cash flow reports.
- Fixed sync issues with popular accounting integrations like QuickBooks.

</Update>

<Update label="2024-08-10" description="v1.4.0" tags={["feature", "bugfix"]}>

## New Features

- **Real-Time Cash Position**: Live updates of your company's cash across all connected bank accounts.
- **Team Permissions**: Granular access controls for viewing and editing treasury data.

## Improvements

- Optimized report generation for faster PDF exports.

## Bug Fixes

- Patched security vulnerability in webhook endpoints.
- Fixed UI glitches on forecast charts in Safari browsers.

</Update>
