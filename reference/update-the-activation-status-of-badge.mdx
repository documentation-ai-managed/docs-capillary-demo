---
title: Update activation status of badge
---

This API allows you to update the activation status of the badge.

<Callout kind="tip" title="Note">

For detailed information about our APIs and for hands-on testing, refer documentation in [API overview](https://docs.capillarytech.com/reference/apioverview) and step-by-step guide on making your first API call in [Make your first API call](https://docs.capillarytech.com/reference/make-your-first-api-call).

</Callout>

## Prerequisites

- [ ] Authentication: Basic or OAuth authentication
- [ ] Default access group

## Resource information

| :------------ | :----------------------------------------------------------------- |
| URI           | /api_gateway/v1/badges/badgeMeta/`{badgeId}`/`{activationStatus}` |
| HTTP method   | PUT                                                                |
| Pagination    | NA                                                                 |
| Batch support | NA                                                                 |

## Example request

<CodeGroup show-lines="true" tabs={["Sample request when activationStatus =activate", "Sample request when activationStatus =deactivate"]}>

  ```bash
  curl --location --request PUT 'https://eucrm.cc.capillarytech.com/api_gateway/v1/badges/badgeMeta/68ccf60d28a4f97c042c83c1/activate' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Basic bWFkaHVI3MjU2YQ==' \
  --data '{
      "active": true
  }'
  ```

  ```bash
  curl --location --request PUT 'https://eucrm.cc.capillarytech.com/api_gateway/v1/badges/badgeMeta/68ccf60d28a4f97c042c83c1/deactivate' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Basic bWFk3MjU2YQ==' \
  --data '{
      "active": true
  }'
  ```

</CodeGroup>

## Request path parameter

| Parameter          | Data Type | Description                                                            |
| ------------------ | --------- | ---------------------------------------------------------------------- |
| activationStatus\* | Enum      | Activation status of the badge. Supported values: Activate, Deactivate |
| badgeId\*          | String    | Unique identifier ("id") generated during the creation of the badge    |

<CodeGroup show-lines="true" tabs={["When activationStatus=activate", "When activationStatus=deactivate"]}>

  ```bash
  https://eucrm.cc.capillarytech.com/api_gateway/v1/badges/badgeMeta/6543688e66a87827bb61e62a/activate
  ```

  ```text
  https://eucrm.cc.capillarytech.com/api_gateway/v1/badges/badgeMeta/6543688e66a87827bb61e62a/deactivate
  ```

</CodeGroup>

## Example response

<CodeGroup show-lines="true" tabs={["Sample response when activationStatus=activate", "Sample response when activationStatus=deactivate"]}>

  ```json
  {
      "data": {
          "id": "68ccf60d28a4f97c042c83c1",
          "isActive": true
      },
      "errors": [],
      "warnings": []
  }
  ```

  ```json
  {
      "data": {
          "id": "68ccf60d28a4f97c042c83c1",
          "isActive": false
      },
      "errors": [],
      "warnings": []
  }
  ```

</CodeGroup>

## Response parameter

| Parameter | Data Type | Description                            |
| --------- | --------- | -------------------------------------- |
| id        | String    | Unique identifier for the badge.       |
| isActive  | Boolean   | Indicates whether the badge is active. |
| errors    | Array     | Contains details of any errors.        |
| warnings  | Array     | Contains details of any warnings.      |
