---
title: Upload Redeemed Coupons
---
Lets you upload coupons that are redeemed for a coupon series in bulk.

You can also import coupons (Capillary CRM) that are redeemed externally using an endpoint.

#### Request Body Parameters

| Parameters                                       | Data type | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------------------ | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `customerIdentifier`\*                           | Enum      | Unique identifier of the customer to update redeemed coupons. Values: `MOBILE`, `EXTERNAL_ID`, `EMAIL`, `USER_ID`.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `couponIdentifier`\*                             | Enum      | Coupon identifier used. Values: `COUPON_ID`, `COUPON_CODE`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `file`\*                                         | File      | The CSV file that contains information of redeemed coupons. Each row in the CSV file can contain the following fields (columns marked with \* are mandatory).Sample file content:_File content sample 1:_`redeemed date in millis, redeemed at, user id, coupon id, bill id, bill number, details1603128622000,50015497,23599838,23456,1603128596000 luci_auto_15039`_File content sample 2:_`redeemed date in millis, redeemed at, mobile, coupon code, bill id, bill number, details1603128622000,50015497,9988776655,ABCDEF1,1603128596000 luci_auto_15039` |
| • `customer identifier`\*                        | String    | Field used to identify the customer, it can be `userId`, `mobile`, `email` or `externalId`. (`userId` will have more preference over the other customer identifiers, in case of multiple values)                                                                                                                                                                                                                                                                                                                                                               |
| • `coupon identifier`\*                          | String    | Field used to identify the redeemed coupon, it can be `couponId` or `couponCode`. (`couponId` has more preference over `couponCode` in case of multiple values)                                                                                                                                                                                                                                                                                                                                                                                                |
| • `redeemed date in millis`\*                    | Long      | Coupon redeemed time in Epoch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| • `redeemed at`\*                                | Integer   | Coupon redeemed till's Id.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| • `bill id`                                      | String    | Transaction Id.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| • `bill number`                                  | String    | Transaction Number.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| • `details`                                      | String    | Additional details for the redeemed coupon.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `uploadHeaders`\*                                | String    | The sequence (starts from 0) of the columns in the attached csv file. This field accepts stringified JSON. Key names for the columns are listed below\.For the above file samples, the uploadHeaders will be:_Sample 1_ - `{"redeemedDateInMillis": 0, "redeemedAt": 1, "billNumber": 5, "couponId": 3, "userId": 2, "billId": 4, "details": 6}`_Sample 2_ - `{"redeemedDateInMillis": 0, "redeemedAt": 1, "billNumber": 5, "couponCode": 3, "mobile": 2, "billId": 4, "details": 6}`                                                                          |
| • `mobile` / `externalId` / `email` / `userId`\* | Integer   | Column index of the customer identifier. The key name varies according to the `customerIdentifier` param: `MOBILE`: `mobile`, `EXTERNAL_ID`: `externalId`, `EMAIL`: `email`, `USER_ID`: `userId`.                                                                                                                                                                                                                                                                                                                                                              |
| • `couponId` / `couponCode`\*                    | Integer   | Column index of the coupon identifier. The key name varies according to the `couponIdentifier` param: `COUPON_ID`: `couponId`, `COUPON_CODE`: `couponCode`.                                                                                                                                                                                                                                                                                                                                                                                                    |
| • `redeemedDateInMillis`\*                       | Integer   | Column index of the redeemed date in milliseconds.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| • `redeemedAt`\*                                 | Integer   | Column index of the redeemed at till's Id.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| • `billId`                                       | Integer   | Column index of the bill Id.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| • `billNumber`                                   | Integer   | Column index of the bill number.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| • `details`                                      | Integer   | Column index of the details.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

All parameters marked with \* are mandatory.
