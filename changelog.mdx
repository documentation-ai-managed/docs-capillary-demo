## Migration Guides

For major updates like v2.0.0, follow these steps to update your integration seamlessly.

<Steps>
<Step title="Update Authentication" icon="lock">
Replace API keys with JWT tokens. Generate tokens via the new auth endpoint.

<CodeGroup tabs="JavaScript,Python">
````javascript
const response = await fetch('https://api.example.com/v2/auth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ client_id: 'YOUR_CLIENT_ID', client_secret: 'YOUR_CLIENT_SECRET' })
});
const { access_token } = await response.json();
````
````python
import requests
response = requests.post('https://api.example.com/v2/auth/token', json={
    'client_id': 'YOUR_CLIENT_ID',
    'client_secret': 'YOUR_CLIENT_SECRET'
})
access_token = response.json()['access_token']
````
</CodeGroup>
</Step>

<Step title="Update Endpoint Calls" icon="settings">
Switch from `v1/loyalty-points` to `v2/loyalty/transactions`.

````javascript
// Old
fetch('https://api.example.com/v1/loyalty-points?customerId=123')

// New
fetch('https://api.example.com/v2/loyalty/transactions?customerId=123', {
  headers: { Authorization: `Bearer ${access_token}` }
})
````
</Step>

<Step title="Test and Deploy" icon="check-circle">
Run integration tests and monitor webhooks for `>24 hours`.
</Step>
</Steps>

<Callout kind="tip">
Check your current version via the API: `GET /v2/status`. Always back up configurations before upgrading.
</Callout>
