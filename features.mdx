## Building Multi-Tier Loyalty Programs

Define tiers based on points earned from purchases. You configure rules for earning and redeeming points.

### Setup Steps

<Steps>
  <Step title="Create Program" icon="plus">
    Navigate to the Loyalty Programs dashboard and click "New Program".
  </Step>
  <Step title="Define Tiers" icon="settings">
    Set tiers with point thresholds:

````json
{
  "tiers": [
    {"name": "Bronze", "minPoints": 0},
    {"name": "Silver", "minPoints": 1000},
    {"name": "Gold", "minPoints": 5000}
  ]
}
````
  </Step>
  <Step title="Activate" icon="check-circle">
    Publish the program to make it live for customers.
  </Step>
</Steps>

## Analytics and Reporting

Monitor key metrics like redemption rates and tier progression.

<Tabs>
  <Tab title="Dashboard View" icon="activity">
    Access real-time KPIs:

````javascript
// Fetch analytics data
const response = await fetch('https://api.example.com/v1/analytics/programs/123', {
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
});
const data = await response.json();
console.log(data.redemptions); // e.g., 1500
````
  </Tab>
  <Tab title="Custom Reports" icon="file-text">
    Schedule exports in CSV or PDF format.
  </Tab>
</Tabs>

<ResponseField name="totalMembers" field-type="integer" required="true">
  Number of active loyalty members.
</ResponseField>
<ResponseField name="redemptionRate" field-type="number">
  Percentage of points redeemed.
</ResponseField>

## Omnichannel Engagement Tools

Reach customers wherever they are.

<CodeGroup tabs="Email,SMS,Push">
````javascript
// Email campaign
await fetch('https://api.example.com/v1/campaigns/email', {
  method: 'POST',
  body: JSON.stringify({
    segmentId: 'vip-customers',
    template: 'welcome-gold'
  })
});
````
````javascript
// SMS campaign
await fetch('https://api.example.com/v1/campaigns/sms', {
  method: 'POST',
  body: JSON.stringify({
    segmentId: 'at-risk',
    message: 'Earn double points this weekend!'
  })
});
````
````javascript
// Push notification
await fetch('https://api.example.com/v1/campaigns/push', {
  method: 'POST',
  body: JSON.stringify({
    title: 'New Rewards Available',
    segmentId: 'gold-tier'
  })
});
````
</CodeGroup>

<Callout kind="tip" title="Best Practice">
Test campaigns on small segments before full rollout to optimize engagement rates.
</Callout>
