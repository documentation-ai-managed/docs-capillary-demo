The Create Cart Promotions API allows you to create promotional offers that apply to shopping carts. This powerful endpoint enables you to configure various types of promotions to incentivize purchases and drive customer engagement.

## API Endpoint

<Request tabs="cURL,JavaScript,Python">
```bash
curl -X POST 'https://host/api_gateway/v1/promotions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "promotion": {
      "name": "Summer Sale 2024",
      "type": "cart_discount",
      "discount_type": "percentage",
      "discount_value": 20,
      "valid_from": "2024-06-01T00:00:00Z",
      "valid_until": "2024-08-31T23:59:59Z",
      "minimum_cart_value": 100,
      "maximum_discount": 50
    }
  }'
```

```javascript
const response = await fetch('https://host/api_gateway/v1/promotions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
  },
  body: JSON.stringify({
    promotion: {
      name: 'Summer Sale 2024',
      type: 'cart_discount',
      discount_type: 'percentage',
      discount_value: 20,
      valid_from: '2024-06-01T00:00:00Z',
      valid_until: '2024-08-31T23:59:59Z',
      minimum_cart_value: 100,
      maximum_discount: 50
    }
  })
});

const data = await response.json();
console.log(data);
```

```python
import requests

url = 'https://host/api_gateway/v1/promotions'
headers = {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
}

payload = {
    'promotion': {
        'name': 'Summer Sale 2024',
        'type': 'cart_discount',
        'discount_type': 'percentage',
        'discount_value': 20,
        'valid_from': '2024-06-01T00:00:00Z',
        'valid_until': '2024-08-31T23:59:59Z',
        'minimum_cart_value': 100,
        'maximum_discount': 50
    }
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()
print(data)
```
</Request>

## Request Parameters

<ParamField body="promotion" param-type="object" required="true">
The main promotion object containing all promotion details.

<Expandable title="Promotion Object Properties" default-open="true">
<ParamField body="name" param-type="string" required="true">
Name of the promotion. This will be displayed to customers and used for internal tracking.

**Example**: `"Summer Sale 2024"`
</ParamField>

<ParamField body="type" param-type="string" required="true">
Type of promotion to create. Determines how the promotion is applied to the cart.

**Possible values**:
- `cart_discount` - Discount on total cart value
- `buy_x_get_y` - Buy X items get Y items free
- `free_shipping` - Free shipping on orders
- `bundle_offer` - Bundle multiple items at special price

**Example**: `"cart_discount"`
</ParamField>

<ParamField body="discount_type" param-type="string" required="true">
Type of discount to apply. Required when type is `cart_discount`.

**Possible values**:
- `percentage` - Percentage discount
- `fixed_amount` - Fixed amount discount
- `points` - Discount using loyalty points

**Example**: `"percentage"`
</ParamField>

<ParamField body="discount_value" param-type="number" required="true">
Value of the discount. Interpretation depends on `discount_type`:
- For `percentage`: Value between 0-100
- For `fixed_amount`: Absolute amount in currency
- For `points`: Number of loyalty points

**Example**: `20` (represents 20% discount)
</ParamField>

<ParamField body="valid_from" param-type="string" required="true">
Start date and time when the promotion becomes active. Must be in ISO 8601 format.

**Example**: `"2024-06-01T00:00:00Z"`
</ParamField>

<ParamField body="valid_until" param-type="string" required="true">
End date and time when the promotion expires. Must be in ISO 8601 format.

**Example**: `"2024-08-31T23:59:59Z"`
</ParamField>

<ParamField body="minimum_cart_value" param-type="number" required="false">
Minimum cart value required to apply the promotion. Specified in the base currency.

**Example**: `100`
</ParamField>

<ParamField body="maximum_discount" param-type="number" required="false">
Maximum discount amount that can be applied. Prevents excessive discounts on high-value orders.

**Example**: `50`
</ParamField>

<ParamField body="usage_limit" param-type="integer" required="false">
Maximum number of times this promotion can be used across all customers.

**Example**: `1000`
</ParamField>

<ParamField body="usage_limit_per_customer" param-type="integer" required="false">
Maximum number of times a single customer can use this promotion.

**Example**: `3`
</ParamField>

<ParamField body="applicable_categories" param-type="array" required="false">
Array of category IDs where this promotion is applicable. If empty or not specified, applies to all categories.

**Example**: `["electronics", "fashion", "home"]`
</ParamField>

<ParamField body="excluded_categories" param-type="array" required="false">
Array of category IDs to exclude from the promotion. Takes precedence over `applicable_categories`.

**Example**: `["sale_items", "clearance"]`
</ParamField>

<ParamField body="applicable_products" param-type="array" required="false">
Array of specific product IDs where this promotion is applicable. If specified, promotion applies only to these products.

**Example**: `["PROD001", "PROD002", "PROD003"]`
</ParamField>

<ParamField body="promotion_code" param-type="string" required="false">
Unique promotional code that customers must enter to activate the promotion. If not specified, promotion is automatically applied.

**Example**: `"SUMMER20"`
</ParamField>

<ParamField body="stackable" param-type="boolean" required="false">
Whether this promotion can be combined with other promotions. Default is `false`.

**Example**: `true`
</ParamField>

<ParamField body="priority" param-type="integer" required="false">
Priority level when multiple promotions are applicable. Higher numbers indicate higher priority. Default is `0`.

**Example**: `10`
</ParamField>

<ParamField body="customer_segments" param-type="array" required="false">
Array of customer segment IDs eligible for this promotion. If not specified, applies to all customers.

**Example**: `["premium", "vip", "gold"]`
</ParamField>

<ParamField body="channels" param-type="array" required="false">
Sales channels where this promotion is available. If not specified, applies to all channels.

**Possible values**: `["online", "mobile_app", "pos", "marketplace"]`

**Example**: `["online", "mobile_app"]`
</ParamField>

<ParamField body="description" param-type="string" required="false">
Detailed description of the promotion for internal reference and customer display.

**Example**: `"Get 20% off on your entire order. Valid for summer season only."`
</ParamField>

<ParamField body="terms_and_conditions" param-type="string" required="false">
Legal terms and conditions for the promotion.

**Example**: `"Offer valid on minimum purchase of $100. Cannot be combined with other offers. Excludes sale items."`
</ParamField>
</Expandable>
</ParamField>

## Promotion Types

<Tabs>
<Tab title="Cart Discount" icon="percent">
Apply a percentage or fixed amount discount to the entire cart.

**Use cases**:
- Seasonal sales
- Flash sales
- First-time customer discounts
- Loyalty rewards

**Configuration**:

```json
{
  "type": "cart_discount",
  "discount_type": "percentage",
  "discount_value": 15,
  "minimum_cart_value": 50
```

<Tab title="Buy X Get Y" icon="gift">
Incentivize customers to purchase more items by offering free products.

**Use cases**:
- Buy 2 Get 1 Free
- Buy 3 Pay for 2
- Product bundling

**Configuration**:

```json
{
  "type": "buy_x_get_y",
  "buy_quantity": 2,
  "get_quantity": 1,
  "applicable_products": ["PROD001", "PROD002"]

```
</Tab>

<Tab title="Free Shipping" icon="truck">
Waive shipping costs to encourage purchases.

**Use cases**:
- Orders above a certain value
- Promotional periods
- Premium customer segments

**Configuration**:

```json
{
  "type": "free_shipping",
  "minimum_cart_value": 75,
  "channels": ["online", "mobile_app"]
```

</Tab>

<Tab title="Bundle Offer" icon="package">

**Use cases**:
- Product combos

## Best Practices

<Steps>
<Step title="Set appropriate validity periods" icon="calendar" title-type="h3">
Ensure your `valid_from` and `valid_until` dates are accurate. Consider time zones and customer shopping patterns when setting these dates.

<Callout kind="tip">
Schedule promotions to start just before peak shopping hours to maximize impact.
</Callout>
</Step>

<Step title="Use usage limits wisely" icon="shield" title-type="h3">
Set `usage_limit` and `usage_limit_per_customer` to prevent abuse and control promotion costs.

- Set global usage limits for high-value discounts
- Limit per-customer usage for expensive products
- Monitor usage patterns and adjust limits as needed
</Step>

<Step title="Configure minimum cart values" icon="shopping-cart" title-type="h3">
Use `minimum_cart_value` to ensure promotions are profitable and encourage larger purchases.

<Callout kind="success">
Promotions with minimum cart requirements typically increase average order values by 20-30%.
</Callout>
</Step>

<Step title="Leverage customer segmentation" icon="users" title-type="h3">
Target specific customer segments with `customer_segments` to maximize relevance and conversion.

**Segmentation examples**:
- New customers: Welcome discounts
- VIP customers: Exclusive offers
- Inactive customers: Win-back promotions
</Step>

<Step title="Test promotions before launch" icon="flask" title-type="h3">
Create promotions with limited usage or specific test segments before full rollout.

<Callout kind="alert">
Always verify discount calculations and exclusions before activating promotions for all customers.
</Callout>
</Step>
</Steps>

## Error Handling

<Callout kind="alert">
Always implement proper error handling when creating promotions. Check the `success` field in the response and handle errors appropriately.
</Callout>

Common error scenarios:

| Error Code | Description | Solution |
|------------|-------------|----------|
| INVALID_REQUEST | Request parameters are invalid | Verify all required fields and validate parameter values |
| UNAUTHORIZED | Authentication failed | Check your API key and ensure it's valid |
| DUPLICATE_PROMOTION | Promotion with same name/code exists | Use a unique name or promotional code |
| INVALID_DATE_RANGE | Invalid validity period | Ensure `valid_from` is before `valid_until` |
| INVALID_DISCOUNT | Discount value is out of range | Check discount_value is appropriate for discount_type |
| CATEGORY_NOT_FOUND | Specified category doesn't exist | Verify category IDs before creating promotion |
| SEGMENT_NOT_FOUND | Customer segment doesn't exist | Verify customer segment IDs |

## Rate Limiting

<Callout kind="info">
The Create Cart Promotions API has rate limits to ensure system stability. Current limits are:

- **100 requests per minute** per API key
- **1000 requests per hour** per API key

If you exceed these limits, you'll receive a `429 Too Many Requests` response.
</Callout>
